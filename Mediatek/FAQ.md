# 广升 Mediatek 相机常见问题

### Q：预览画面有红色 Demo 字样和白色 Adups 字样  
 
这是为了防止算法运行在未经允许的设备上而做的措施。  

**解决方式：**  

如果是我们的合作客户，可以按照以下流程给客户授权，授权后 Demo 和 Adups 字样会消失。  

需要客户在安装了 adb 环境的电脑上用数据线连接需要授权的设备，在电脑上执行命令  

```adb shell getprop > YourProject.txt```

然后将生成的**YourProject.txt** 文件发给我们开发或者 PM，我们会根据项目信息进行授权。  
授权结果为一个移植包 Patch，里面包含了多个 license，将它发给客户并移植到源码内重新编译后的 ROM 将不再有 Demo 和 Adups 字样。  
可通过在 remount 后（必须是 userdebug ROM）的设备上，将内容 push 到设备指定目录即可快速验证消除 Demo 和 Adups 字样。  
（开发提供的 patch 一般会自带 push 脚本，只需要先解锁设备的 BL 再执行脚本，脚本会自动 remount + push）  

**授权分为永久授权和临时授权：**  
* 永久授权：已付费的合作客户项目根据项目属性授权到 2099年。
* 临时授权：售前项目、用于演示、项目属性为公共名词的（比如：Android，Neutral，alps等），不限项目授权到当前时间的一段时间后，比如一年、半年（具体要求根据商务要求来定）。


### Q：为何已经永久授权的或在临时授权时间范围内的项目又出现了红色 Demo 或者 白色 Adups

说明设备属性已经发生变化，算法的 license 验证器判断出和上次授权的项目不是同一个。  

**解决方式：**  

按照上文的授权流程重新走一遍即可解决。
